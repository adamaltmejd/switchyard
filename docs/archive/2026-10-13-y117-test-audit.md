## Assertion gate

Keep G1's existing worker exclusion scenario and queue positive control.
Replace only its negative socket observation. The old block accepted every
nonzero curl exit, including a timeout, and even accepted missing output.
The host now checks that the daemon path is a Unix socket. The worker's
real boxed shell tests visibility of that same path. The observer requires
the exact line `socket=1`, the shell's false result for an inaccessible or
absent path. No request timeout can supply that result.

This establishes G1's existing no-RPC worker exclusion clause through the
host/box boundary. Expected values come from host filesystem metadata,
the shell's `test` result and the spec's mount exclusion. The socket path
is an observer location, not a file-layout contract.

Sabotage: mount the daemon state directory into the worker box at its host
path. The socket becomes visible and the new assertion fails. Canonical
exclusion cannot catch a mount of only the daemon state directory. The
MCP probe observes a separate HTTP session boundary. The worker probes
after committing, in the same model turn, with its real clone and bearer.
No new scenario or binary path is added.

The same project still approves the actual candidate, waits for
`landing.recorded` and proves ancestry through host git. The sessionless
MCP probe still requires 404. It does not detect adding a daemon method
behind the session check. That limitation remains in the test comment.
