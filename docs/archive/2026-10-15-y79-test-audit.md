## Operation disposition

methods. ARCHITECTURE.md now enumerates that supported table. Service
run/install/uninstall/status/restart, version and operator MCP startup remain
executable entrypoints. Task/project/status/attempt/proposal CLI parsing,
dispatch, project discovery, history streaming and board rendering are
deleted. No argv translator or fallback surface replaces them.

through a real initialized operator MCP process and the real daemon socket.

selection, approval/rejection, proposal decisions and inspection. Numeric
identities remain JSON integers; arrays and booleans keep their native types.
The old CLI helpers are gone. Only the two explicit pre-target upgrade
fixtures select the genuine archived executable's CLI for historical setup
and observation. After selecting the successor they use MCP. No historical
runtime is simulated and no version-detecting dispatcher exists.

Existing independently selectable host scenarios retain their Git, store,
host, native box and scripted-model observations. This is an observer
migration, not a claim that every secondary operation has a dedicated test.
No test asserts removed argv or help shapes.

## G7 gate: waits and transport lifetime

Audit the current suite rather than resurrecting the historical line-number
probe. `operator_wait_cancellation_keeps_work_and_worker_grants_separate`
retains its real held worker, accepted wait cancellation, stdin EOF, stale
identity and worker/operator boundary checks. Releasing held work still
reaches approval and landing. A ping orders adapter acceptance; it does not
prove the daemon's initial attention sample. Its comment now limits the
claim to cancellation/EOF isolation.

Both product clauses remain exact: idle `since` ignores older attempt ends,
and `since` past an open item waits for a newer item. Their initial-sample
waiting condition is deliberately untested. The current fixture provides
no external held point for that sample. No new fixture, clock wait, retry,
private binary barrier or immediate-child scheduling claim replaces it.
The G7 Shown by column describes the retained cancellation/EOF proof and
does not advertise those two semantic probes. This is the operator's
explicitly authorized selective coverage disposition, not a product change.

Shared history reads ordered bounded `events` pages. It forwards each
strictly increasing sequence before advancing its cursor; empty pages keep
the cursor. EOF, API error or malformed history closes observation without
reconnecting. Event waits fail on closure. A separate fixture-held FIFO can
continue after planned daemon death, preserving crash observation while
ordinary event waits cannot treat a closed stream as success. Dropping an
observer kills only its adapter; it sends no product stop operation.
