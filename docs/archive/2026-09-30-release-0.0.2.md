# Release 0.0.2, 2026-09-30

The pre-release pass for yard 0.0.2, from `v0.0.1` (`b196825`).

## What is in it

- `yard project forget` retires the project's pinfold image name (Y-53).
  A build queued behind the forget does not recreate it. The CLI resolves
  the path.
- pinfold 0.1.0 is required. It fixes the Mac suite's
  `buildkit not found` failure: concurrent Apple builds with different
  `NO_COLOR` settings replaced each other's builder (pinfold #77). It also
  closes #71 to #75.
- `status --watch` help names its idle and `--since` exits.
- The e2e suite went from 75 scenarios to 36, in two passes:
  `2026-09-29-lean-code-cleanup.md` (Mac) and
  `2026-09-30-linux-test-audit.md` (Linux). The operator approved every
  clause a cut weakened. The guarantee rows in ARCHITECTURE.md match what
  remains.

## Gate

- **Code-cleanup and test-audit sweep.** The whole-tree sweep ran at
  `d004996` (`2026-09-29-lean-code-cleanup.md`). The Linux cost sweep ran
  at `9f5a82a`. Y-53, the only binary change after `d004996`, was read
  separately. Its daemon-side path resolution was a duplicate of the
  CLI's and is deleted (`eafa004`).
- **Y-53 by hand.** A scratch project built `yard-<key>`. `forget` from
  its parent, with a relative path, removed the image id. A second
  `forget` removed nothing, and the dogfood project stayed registered.
- **Spec and README pass.** Since `v0.0.1` the spec changed in five
  places: four trimmed guarantee rows and the `forget` line. Each matches
  its tests. Nothing else was outdated or resolved.
