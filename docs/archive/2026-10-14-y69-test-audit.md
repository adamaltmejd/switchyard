The existing concurrent reader case has one writable producer. It cannot
catch shared writable indexes, sessions or proof staging, or a reader bound
to the wrong independent producer. Its assertions remain as controls for
shared capacity and exact joins. The new extension holds all five real
implementers together before releasing any publication. This exercises the
requested five-profile mechanism rather than five sequential invocations.

Same-workspace refusal names the exact owner execution. Independent writers
and deliberate same-workspace continuation in the same project are allowed
controls. Ambiguous stop and undeclared reuse have explicit named stop and
declared continuation controls. Read-only refusal has the writers' successful
writes as its control. No timeout, sleep, retry, mock or binary barrier proves
an assertion.

## Crash point and bounded source checks

The fifth successor is held at a real host-model request after changing its
partial tree. Before daemon death the test observes its real box and busy
inherited effect lock. The asynchronous real-child wrapper preserves original
stdin in an unused descriptor and closes only that temporary descriptor in
parent and child. It forwards the real child status. It holds after real
child exit on a host FIFO, retaining inherited locks. Before restart the test
proves the running/reserved row, busy lock and partial file. After restart it
proves box absence without lock freedom, refusal naming that owner, immutable
prior candidates and no duplicate execution. Release precedes explicit retry.
