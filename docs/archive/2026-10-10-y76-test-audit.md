assertion blocks establish the new G7 Shown by clause:

- Fresh completion removes only cost from real stdout. The CLI record must
  preserve null with unknown/unreported metadata. This catches absent cost
  becoming zero. Explicit zero on a later resumed completion is the control.
- A resumed tool response followed by a host HTTP 400 produces a real failed
  result. Fixture counters, actual result fields and execution identity must
  agree. This catches adding observed tokens to terminal totals or counting
  previous session usage. Failure completeness stays partial.
- A resumed tool response with multiple content blocks is followed by a held
  model request. Taking down the real box drains stdout without a result.
  The record must retain exactly the reported fixture increments, null cost
  and partial token metadata. This catches terminal-only recording and
  duplicate message counting. Reopening must preserve that same record.
- The final resumed completion must report only its new fixture counters,
  complete metadata and explicit zero cost. Raw unmodified resumed estimates
  are compared with the fresh raw estimate for identical fixture counters,
  scaled by the fixture reply count. This detects accumulated session cost
  without deriving any expected price from a catalog or Yard logic.
